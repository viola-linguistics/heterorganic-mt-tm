# heterorganic-mt-tm
Words containing heterorganic nasal-obstruent and obstruent-nasal clusters in nine languages.

This repository contains words from nine languages containing nasal-obstuent and obstruent-nasal clusters, where the two sounds have a different place of articulation. The languages are: Arabic, Ukranian, Russian, French, Slovak, Lithuanian, German, Czech, Greek.
I looked at 3 different places of articulation: cor, palatal and velar, the obstruents are either [+voice] or [-voice].
The IPA-transcriptions are from Wiktionary.
